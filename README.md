# アプリで合格！第二種電気工事士

第二種電気工事士試験（筆記試験・技能試験）の合格を目指すための学習用Webアプリです。

## 主な機能

- **一問一答・過去問演習**：分野別・出題数を選んでオリジナル問題を演習できます（現在40問）
- **苦手分野の分析・復習機能**：分野別正答率を可視化し、間違えた問題をまとめて復習できます
- **配線図・複線図の練習**：技能試験の候補問題を想定した単線図から複線図への展開を、チェックリストと一問一答で練習できます

問題データは著作権に配慮し、実際の過去問ではなくオリジナルで作成したサンプル問題です。進捗データはブラウザのlocalStorageにのみ保存され、サーバーへの送信は行いません。

## セットアップ

```bash
npm install
npm run dev
```

## その他のコマンド

```bash
npm run build   # 本番ビルド
npm run preview # ビルド結果のプレビュー
npm run test    # ユニットテスト実行
npm run lint    # Lint実行
```
